Topological Protection and Threshold Scaling in Planar Surface Codes

Dr. Elena Rostova
Institute for Quantum Optics, Zurich
Abstract

We derive the sub-threshold logical error suppression law for planar stabilizer lattices under asymmetric Pauli-Z biased noise and validate decoder runtime scaling up to code distance d = 21.

1. Stabilizer Formalism on a Planar Lattice

A planar surface code of distance ddd embeds n=d2+(d−1)2n = d^2 + (d-1)^2n=d2+(d−1)2 physical data qubits onto the edges of a square lattice with rough and smooth boundary conditions. The code space C\mathcal{C}C is defined as the simultaneous +1+1+1 eigenspace of mutually commuting vertex (AvA_vAv​) and plaquette (BpB_pBp​) operators:

Because every vertex shares either zero or two edges with any plaquette, [Av,Bp]=0[A_v, B_p] = 0[Av​,Bp​]=0 holds identically across the lattice. Logical operators Xˉ\bar{X}Xˉ and Zˉ\bar{Z}Zˉ correspond to non-trivial relative homology chains connecting opposite boundaries, yielding a single encoded logical qubit with commutation relation {Xˉ,Zˉ}=0\{\bar{X}, \bar{Z}\} = 0{Xˉ,Zˉ}=0.

import numpy as np

def logical_error_rate(p: float, p_th: float, d: int, c: float = 0.08) -> float:
    """Compute leading-order sub-threshold logical error probability."""
    exponent = (d + 1) / 2.0
    return c * np.power(p / p_th, exponent)
